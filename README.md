# CarPooling System

A web-based CarPooling System developed using Python, Flask, HTML, CSS, JavaScript, and MySQL.

## Features

* User Registration and Login
* Offer a Ride
* Search for Available Rides
* Book Rides
* View My Rides and Bookings
* MySQL Database Integration

## Technologies Used

* Python
* Flask
* HTML and CSS
* JavaScript
* MySQL

## Project Purpose

The purpose of this project is to help users share rides, find available rides, and manage bookings through a simple web application.

Currently under development.
